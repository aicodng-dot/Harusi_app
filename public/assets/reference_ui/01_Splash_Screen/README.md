# Reference UI - 01_Splash_Screen derivatives

These production assets were derived from the immutable approved reference
`reference UI/01_Splash_Screen.png` (SHA-256
`99CDC55D092422EE8146AE95D93CAFDF0DD99E9A3C1BC1A58849F6C1FDB9A484`).
The original file was not modified and is not used as a page background.

Crop coordinates use `[left, top, right, bottom)` in original 863 x 1822 PNG pixels:

- `01_Splash_Screen_PangaEvents_Mark.png`: `[326,406,532,702)`; gold pixels retained with transparent non-logo pixels.
- `01_Splash_Screen_Leaves_Top.webp`: `[610,170,863,510)`; softly feathered at the left and bottom edges.
- `01_Splash_Screen_Leaves_Left.webp`: `[0,330,300,720)`; softly feathered at the top, right and bottom edges.
- `01_Splash_Screen_Leaves_Right.webp`: `[690,820,863,1650)`; softly feathered at the top, left and bottom edges.
- `01_Splash_Screen_Leaves_Bottom.webp`: `[0,1430,240,1750)`; softly feathered on all crop edges.

The decorative crops exclude the simulated status bar, rounded phone corners and
all interactive content. Logo text, tagline, feature text, progress dots and the
navigation target remain real HTML/CSS.
