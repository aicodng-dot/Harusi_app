# Working Flow 18 — Invitation Design Quality Assurance

Run focused quality assurance on the template catalogue/editor/preview only. Test all existing templates, color combinations, long and short names, both languages, missing optional fields, photos of varied aspect ratios, narrow phones and print exports. Check no clipping, text collisions, low contrast, distorted images or broken assets. Verify output dimensions and consistency between preview and export. Fix only defects in this flow. Do not begin guest management. Stop.
