# Working Flow 16 — Custom Photo & Artwork Upload

Implement secure photo and artwork upload for the invitation editor. Support approved image formats, file-size/dimension validation, orientation correction, crop/reposition and replacement. Keep originals and optimized derivatives appropriately; prevent path traversal, SVG/script injection and unauthorized cross-event access. Preserve design layer references when replacing an image. Do not make photos public by guessable URL. Add focused upload, validation, authorization and rendering tests. Stop.
