# Working Flow 17 — Invitation Preview & Finalization

Implement a high-fidelity preview using exactly the same renderer and layout rules as final export. Show realistic event data, long names, optional host-family wording, date/time/location, photo slots and a reserved QR placement preview. The preview QR must be clearly non-scannable and must never be mistaken for a real credential. Validate missing fields and text overflow. Allow save/finalize without generating guest credentials. Add SW/EN and responsive visual tests. Stop.
