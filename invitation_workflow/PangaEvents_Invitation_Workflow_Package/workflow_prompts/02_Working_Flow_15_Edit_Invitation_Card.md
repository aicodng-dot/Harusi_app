# Working Flow 15 — Invitation Card Editor

Implement the actual invitation editor using the existing premium template assets. Keep background artwork, decorative elements, text, photos and QR placement as separate layers.

Allow editing of couple/celebrant names, host family names, optional host introduction, invitation wording, date, time, venue, dress code, fonts, font sizes, alignment, text positions, background/text/accent/decorative colors and photo slots. Allow image upload, crop, reposition, replace and remove. Support undo/redo, reset-to-template, save draft and autosave only if consistent with the existing app.

Provide a polished responsive editor with live preview, mobile-friendly controls, clear SW/EN localization and safe-area guides. Prevent clipped text, overlapping elements and distorted photos. Do not change admission allowances or QR credentials. Persist a versioned design document with strict validation and event/workspace authorization. Add focused tests and screenshots. Stop after this flow.
