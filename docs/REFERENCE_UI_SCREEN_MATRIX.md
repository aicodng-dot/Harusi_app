## Legend and gate rules

- **CURRENT** route/view means present in inspected source. A **legacy admin analog** is available only to its existing admin authority; it is not an authorized customer route. The existing customer workspace home/setup does not establish customer event, guest, invitation, report, settings or billing functionality.
- **MISSING** means no matching current web route/view contract was found. A filename on disk, planned API, webhook acknowledgment or adjacent operational log is not proof of a functioning journey.
- Every target-file cell is **PLANNED**. A new path is proposed only and does not exist; an existing path denotes a future visual adaptation, not a completed design. Final task contracts may refine component extraction while retaining this screen ID.
- **NOT STARTED** describes adoption of the approved reference design. **BLOCKED** in backend/functional QA identifies a missing contract or gated customer exposure; it is not a claim that an existing backend operation is broken.
- **Visual QA: NOT RUN (reference inspected)** means only the original reference was examined. Later QA must render the implemented screen, compare its hierarchy and states, and record evidence at all required widths in SW/EN. A phone rim, drawn OS status row or home indicator is presentation framing, not app DOM chrome.
- **Functional QA: NOT RUN** is independent of historical regression results. Later tasks must exercise real supported actions, keyboard/focus, loading/empty/error/retry states, navigation and authorization. Missing features remain explicitly BLOCKED until their owning phase supplies a reviewed backend.
- Proposed reusable components below describe future responsibilities. They do not assert that a component file exists. Preserve real backend fields, CSRF, throttles, role/workspace/event boundaries, secure QR tokens, four-digit manual codes, pass capacity and offline protocols. RSVP, delivery and admission remain separate state systems.
- References with EN selected but Swahili copy require a consistent working locale, not literal reproduction of the contradiction. Mock names, counts, phone numbers, table numbers, percentages, QR shapes and provider claims must be replaced by authoritative data. Colors are approximate visual observations unless separately sampled; no raster proves a font identity.
